# Audit Web FindIT (Laravel) vs Mobile (Flutter + Supabase)

Tanggal: 2026-11-09 · Cakupan: `C:\laragon\www\findit` (commit `3f91fdf`) dibandingkan dengan
skema Supabase `ulrxqbvccwhcvywssjfb` dan aplikasi mobile terbaru.

## Konteks arsitektur

- Web login lewat **Supabase Auth** (`App\Services\SupabaseAuth`), sama dengan mobile. Profil di tabel `profiles`.
- Web membaca/menulis database Supabase **langsung lewat koneksi Postgres sebagai role `postgres`**
  (`DB_USERNAME=postgres.<ref>`). Role ini melewati semua RLS, column grant, dan policy yang
  melindungi mobile. Seluruh otorisasi web bergantung pada kode Laravel.
- Admin hanya bekerja lewat web (`/admin`, middleware `admin` → `profiles.role = 'admin'`).

## Yang sudah baik

- Login, daftar, dan OTP memakai Supabase Auth dengan validasi domain `@bsi.ac.id`; rate limit login 5 percobaan.
- Klaim: tidak bisa mengklaim laporan sendiri, cek duplikat, captcha.
- Testimoni: kepemilikan dicek di setiap aksi.
- Persetujuan laporan dari web otomatis memicu email + notifikasi in-app lewat trigger Supabase (tidak perlu kode tambahan di web).
